# Treinamento técnico DryRun Security

Treinamento em português do Brasil com **25 módulos e 25 laboratórios**, cobrindo configuração, execução, governança, integrações e solução de problemas.

## Material

- [Treinamento completo em PDF — 43 páginas](docs/treinamento-tecnico-dryrun-pt-br.pdf)
- [Kit de laboratórios em ZIP](docs/kit-treinamento-dryrun.zip)
- [Conteúdo editável em Markdown](laboratorios/treinamento-fonte.md)
- [Scripts e instruções dos laboratórios](laboratorios/README.md)

## Conteúdo

1. **Getting Started:** documentação e Quick Start.
2. **Scanning:** PR Scanning, SCA, DeepScan, Secrets, IaC, linguagens e matriz de cobertura.
3. **Platform:** Reporting, Risk Register, Code Security Intelligence, configurações, políticas, contexto, feedback, blocking, permissões, MCP e API.
4. **API Integrations:** webhooks, Jira, chaves de API, remediação e DryRun Skill.

Cada módulo apresenta explicação técnica, caso de uso, laboratório, comandos, resultados esperados e diagnóstico de falhas. O material inclui Git/GitHub, Codex/MCP e Jira Cloud.

## Como começar

Leia a preparação do ambiente no PDF. Use um repositório privado dedicado para executar os exercícios; alguns introduzem vulnerabilidades intencionais. Não mescle essas versões em código de produção. Os scripts deste repositório são material didático e não contêm credenciais.

Os exemplos locais foram verificados na autoria. A execução das integrações depende das suas credenciais e permissões; não foi realizada em suas contas durante a elaboração.
